# PaydayMap: Paycheck Budget

Source-free product tour, workflow/support guide, privacy policy and original iPhone/iPad marketing campaigns for a manual paycheck-window planner. Native commercial source and private QA remain in a separate private repository.

Status October23,2026: in production; Apple metadata/product setup and production QA underway. Not submitted, approved or released. TestFlight skipped by publisher instruction.

[Product tour](https://sepidehdalir.github.io/paydaymap/) · [Support](https://sepidehdalir.github.io/paydaymap/support.html) · [Privacy](https://sepidehdalir.github.io/paydaymap/privacy.html)

Images use actual native app screens and its generated PDF with fictional records. Figures are manual estimates, not banking or financial advice. There is no developer backend, bank connection, analytics, advertising or tracking. Apple manages optional purchases. Each currency remains separate.
